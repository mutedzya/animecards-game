# AnimeCards Pack Edition

- Start with 100 coins
- +100 coins once per day
- 1 pack = 10 coins
- 1 pack = 3 random cards
- Every duplicate gives +5 coins
- Collection and coins are saved with localStorage

Add images to `characters/` and edit `data/characters.json`.

This is a client-side GitHub Pages prototype. A real anti-cheat system requires server-side accounts, coins and pack rolls.
